## Q1: What is LLM

A **Large Language Model (LLM)** is a type of generative artificial intelligence built upon the **Transformer architecture** that utilizes deep learning techniques to process, understand, and generate human-like text.

### Core Concepts
*   **Architecture:** LLMs rely on the **Transformer** model, specifically the **self-attention mechanism**, which allows the model to weigh the importance of different words in a sequence regardless of their distance from one another.
*   **Scale:** "Large" refers to both the massive **parameter count** (often billions) and the vast **unstructured datasets** (petabytes of text) used during pre-training.
*   **Probabilistic Nature:** LLMs are essentially **next-token predictors**. They calculate the probability distribution of the next token in a sequence based on the context provided by preceding tokens.

### Key Technical Phases
1.  **Pre-training:** The model learns grammar, facts, and reasoning patterns via self-supervised learning on massive corpora (e.g., Common Crawl, Wikipedia).
2.  **Fine-tuning:** The model is specialized for tasks (e.g., instruction following) using **Supervised Fine-Tuning (SFT)**.
3.  **Alignment:** Techniques like **RLHF (Reinforcement Learning from Human Feedback)** are applied to ensure outputs are helpful, honest, and harmless.

### Real-World Example
Consider a coding assistant. When you prompt it with `def calculate_fibonacci(n):`, the model doesn't "know" the function; it computes the high-probability sequence of tokens that follows that specific syntax based on the millions of code repositories it was trained on.

```python
# The model predicts the next token based on learned probability distributions
prompt = "The capital of France is"
# Model output: " Paris" (Probability: 0.98)
```

### Summary
An LLM is a high-dimensional statistical engine that maps input sequences to output sequences. Its power lies in **emergent properties**—capabilities like reasoning, summarization, and code generation that arise solely from scaling compute, data, and parameter count within the Transformer framework.
