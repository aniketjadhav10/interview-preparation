## Q1: What is LLM?

## 1. Spoken Answer
An LLM, or Large Language Model, is a type of AI trained on massive amounts of text to predict the next word in a sequence. Think of it like a super-advanced version of the autocomplete feature on your phone. By learning patterns in how humans write, it can generate coherent essays, write code, or answer complex questions. In short, it is a statistical engine that turns massive data into a tool for understanding and creating human language.

## 2. Key Points
*   **Large:** Refers to both the massive dataset (trillions of words from the internet) and the number of parameters (the "knobs" the model adjusts during training).
*   **Language Model:** A system that calculates the probability of a word appearing given the words that came before it.
*   **Transformer Architecture:** The underlying "engine" that uses a mechanism called **Attention** to weigh the importance of different words in a sentence, regardless of how far apart they are.
*   **Training Process:** The model is first "pre-trained" to predict missing words, then "fine-tuned" with human feedback to follow instructions and be helpful.
*   **Tokens:** The model doesn't read words; it reads "tokens," which are chunks of characters (like syllables or short words) that it converts into numbers (vectors).
*   **Parameters:** These are the internal variables the model learns during training; they represent the model's "knowledge" or memory of language patterns.

## 3. Code Example
```python
# A conceptual look at how an LLM predicts the next word
import torch
import torch.nn.functional as F

# Imagine the model has scores for these 3 words as the next choice
logits = torch.tensor([2.0, 1.0, 0.1]) 

# Convert scores to probabilities that add up to 100%
probabilities = F.softmax(logits, dim=0)

# The model picks the word with the highest probability
predicted_index = torch.argmax(probabilities).item()
print(f"The model predicts the word at index: {predicted_index}")
```

## 4. Real-World Example
LLMs power modern chatbots like ChatGPT, which use these probability patterns to hold a conversation that feels natural rather than robotic.

## Q2: How are LLM trained?

## 1. Spoken Answer
LLMs are trained by showing a computer billions of sentences from the internet and asking it to guess the next word. Every time it guesses wrong, the model adjusts its internal settings to be slightly more accurate next time. After doing this trillions of times, it learns the patterns, logic, and facts hidden within human language. Essentially, it’s a massive game of "predict the next word" played at a scale no human could ever achieve.

## 2. Key Points
*   **Pre-training:** The initial phase where the model learns general language patterns from massive datasets (like Wikipedia, books, and code).
*   **Next-Token Prediction:** The core mechanism where the model takes a sequence of words and calculates the probability of the next word in the sequence.
*   **Weights/Parameters:** The "internal settings" or numerical values that the model adjusts during training to improve its predictions.
*   **Backpropagation:** The mathematical process of looking at the error (the difference between the guess and the actual word) and moving backward through the model to update the weights.
*   **Fine-tuning:** A second, smaller training phase where the model is shown specific examples (like Q&A pairs) to learn how to follow instructions or act like a helpful assistant.
*   **RLHF (Reinforcement Learning from Human Feedback):** A final step where humans rank different model outputs, teaching the model to prefer answers that are helpful, honest, and safe.

## 3. Code Example
```python
import torch

# A tiny example of the "next token prediction" logic
# Imagine our vocabulary is: {"I": 0, "love": 1, "AI": 2}
logits = torch.tensor([2.0, 0.5, 0.1]) # The model's "guesses" for the next word
target = torch.tensor(1)              # The actual correct word is "love"

# Calculate how "wrong" the model was
loss_function = torch.nn.CrossEntropyLoss()
loss = loss_function(logits.unsqueeze(0), target.unsqueeze(0))

# This 'loss' tells the model how much to adjust its internal weights
print(f"The model's error is: {loss.item():.4f}")
```

## Q3: What is prompt engineering?

## 1. Spoken Answer
Prompt engineering is the art of crafting the instructions you give to an AI model to get the best possible result. Think of it like giving clear, step-by-step directions to a very talented but literal-minded assistant. By changing how you phrase your request, you can guide the AI to be more accurate, creative, or professional. It is essentially the bridge between human intent and machine output.

## 2. Key Points
*   **Definition:** The practice of designing and refining inputs (prompts) to guide Large Language Models (LLMs) toward specific, high-quality outputs.
*   **Context Setting:** Providing the AI with a "persona" or background information helps it understand the tone and constraints of the task.
*   **Few-Shot Prompting:** Giving the model a few examples of the input-output pattern you want before asking it to perform the actual task.
*   **Chain-of-Thought:** Instructing the model to "think step-by-step" before providing an answer, which significantly improves performance on logic and math problems.
*   **Constraints:** Explicitly telling the model what *not* to do (e.g., "do not use jargon," "keep the answer under 50 words").
*   **Iterative Refinement:** The process of testing a prompt, observing the output, and tweaking the wording until the desired consistency is achieved.

## 3. Code Example
```python
# A simple example of prompt engineering using a template
def generate_prompt(user_query, persona="helpful assistant"):
    # We structure the prompt to give the AI a clear role and instructions
    prompt = f"""
    You are a {persona}. 
    Please answer the following user query clearly and concisely.
    
    User Query: {user_query}
    
    Answer:
    """
    return prompt

# Testing the prompt
print(generate_prompt("What is photosynthesis?", persona="science teacher"))
```

## 4. Real-World Example
When you use a chatbot to summarize a long legal document, your prompt—"Summarize this in three bullet points for a non-lawyer"—is prompt engineering in action.

## 7. Common Mistakes Candidates Make
*   **Over-complicating:** Trying to use "magic words" or complex syntax that doesn't actually help the model.
*   **Ignoring Context:** Forgetting that the model has no idea what you are thinking unless you explicitly state the goal and constraints.
*   **Treating it as a silver bullet:** Assuming prompt engineering can fix a model that isn't capable of the task or has bad underlying data.

## 8. If You Want to Sound Senior
*   **Prompt Injection Risks:** Acknowledge that prompt engineering is a security surface; you must design prompts to be resilient against users trying to "jailbreak" or override your system instructions.
*   **Cost vs. Performance:** Understand that longer, more descriptive prompts increase token usage, which impacts both latency and API costs in production systems.
*   **Evaluation Frameworks:** Mention that prompt engineering should be data-driven; use automated evaluation pipelines (like RAGAS or LLM-as-a-judge) rather than just "vibes-based" testing.
